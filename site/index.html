Perry-WIT

TypeScript to WebAssembly

Compile a supported subset of TypeScript into WASI 0.3 components.

Try the playground

Perry-WIT emits WebAssembly instructions without an embedded JavaScript engine. WIT defines the types and functions a component exposes, so other languages and compatible hosts can call it.

TypeScript

export function greet(name: string): string {
  return "Hello, " + name;
}

WIT

package example:greeting;
world greeting {
  export greet: func(name: string) -> string;
}

Async exports, promises and fetch use WASI 0.3. Conformance tests compare supported behaviour with Node.js.

Build

  • CLI — build the compiler from its Nix flake. 
    nix build github:ahirner/perry-wit#perry-wit
  • Rust library — compile source bytes from Rust. API docs and examples.
  • Wasm compiler — the compiler itself, packaged as a portable component. Download .wasm · Compiler API (WIT) · Wasm distribution notices.
