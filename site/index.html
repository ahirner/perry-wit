Perry-WIT

TypeScript to WebAssembly

Compile static TypeScript ahead-of-time into WASI 0.3 WebAssembly components.

Try the playground

Perry-WIT emits native WebAssembly instructions without an embedded JavaScript engine. WIT definitions specify exported interfaces, enabling direct interoperation across languages and WebAssembly hosts.

TypeScript

export function greet(name: string): string {
  return "Hello, " + name;
}

WIT

package example:greeting;
world greeting {
  export greet: func(name: string) -> string;
}

Asynchronous exports, promises, and HTTP fetch run on native WASI 0.3 primitives. Conformance tests verify behavior against Node.js.

Build

  • CLI — build the compiler from its Nix flake. 
    nix build github:ahirner/perry-wit
  • Rust library — compile in-memory source buffers from Rust. API documentation.
  • Wasm compiler — the compiler itself, packaged as a portable component. Download .wasm · Compiler API (WIT) · Wasm distribution notices.
