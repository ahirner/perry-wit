TypeScript to WebAssembly components

Perry-WIT compiles static TypeScript ahead of time into standalone WASI 0.3 components. A WIT world defines the contract and lowers directly to WebAssembly instructions.

What to build

Typed library components

The WIT world declares the exports and generates the .d.ts types. A component exporting a string function is about 3 KB, and each call's temporaries are freed when it returns.

Authoring

Concurrent I/O

fetch, streams, timers and files suspend through WASI 0.3 callbacks and resume directly from host events. {{contractCount}} contracts verify equivalence against Node.js.

Semantics

Integer-typed numbers

WIT u8 to u64 refine TypeScript's number. Arithmetic proven to stay in range compiles to integer instructions instead of floating point.

Numbers

Compilers in your host

Compile tenant TypeScript in-memory from Rust with perry_wit::api, or run the compiler itself as a WASI 0.2 component.
