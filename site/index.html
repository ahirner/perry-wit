TypeScript to WebAssembly components

Perry-WIT compiles static TypeScript ahead of time into standalone WASI 0.3 components. A WIT world defines the contract and lowers directly to WebAssembly instructions.

Try the playgroundRead the handbook

TypeScriptindex.ts

export function greet(name: string): string {
  return "Hello, " + name;
}

WITworld.wit

package example:greeting;
world greeting {
  export greet: func(name: string) -> string;
}

What to build

HTTP services

Write handle(request) against generated types and serve it as wasi:http/handler@0.3.0. fetch, streams and timers suspend through WASI 0.3 callbacks and resume directly from host events.

HTTP handlers

Typed components

The WIT world declares the exports and generates the .d.ts types. A component exporting a string function is about 3 KB, and {{contractCount}} contracts verify equivalence against Node.js.

Authoring

Integer-typed numbers

WIT u8 to u64 refine TypeScript's number. In-range arithmetic compiles to integer instructions.

Numbers

Compile on the fly

Compile tenant TypeScript in-memory from Rust with perry_wit::api, or run the compiler itself as a WASI 0.2 component.
